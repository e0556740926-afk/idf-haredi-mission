# Duet

מערכת הפעלה פיננסית למשק בית — לזוגות שמנהלים בית ביחד ולא מוותרים על פרטיות.

## התחלה

```bash
npm install
npm run test:data    # בדיקות חוזה הנתונים — חייב לעבור
npm run dev
```

**שלב נוכחי:** כל הפרונט מעל נתוני דמה. אין מסד נתונים. חיבור Supabase — שלב נפרד אחר כך.
