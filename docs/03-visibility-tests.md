# מטריצת בדיקות הדליפה

`npm run test:leak`. **חוסם commit ו-deploy.** אם בדיקה כאן נכשלת — עוצרים הכול.

הרעיון: לכל נתיב שבו נתון יכול לצאת מהמערכת, יש בדיקה שמנסה **במפורש** לחלץ דרכו מידע של הצד השני.

## שחקנים

- **דנה** — בעלת 2 חשבונות: אחד `summary_only`, אחד `private`.
- **יואב** — בעל חשבון אחד `summary_only`.
- **הבית** — 3 חשבונות `shared`.
- **זרה** — משתמשת ממשק בית אחר לגמרי.

## המטריצה

## כללי כתיבה לבדיקות האלה

- הבדיקות רצות **מול Postgres אמיתי** עם JWT של משתמש אמיתי — לא מוקים ולא service_role.
- בדיקה 5 בודקת את **סכמת ה-view**, לא רק את הערכים: `information_schema.columns` לא מכיל את העמודות האסורות.
- בדיקה 8 מודדת זמן — הדלפה דרך timing היא הדלפה.
- בדיקה 21 בודקת מחרוזת: אם `"זארה"` מופיעה בהקשר של יואב — נכשל.
- כשמוסיפים view או RPC חדש — **מוסיפים שורה למטריצה באותו PR**. PR שמוסיף גישה לנתונים בלי בדיקה מתאימה נדחה.
