# מערכת העיצוב — מחולצת מ-`design/prototype.html`

הפרוטוטייפ הוא **חוזה חזותי מחייב**. הערכים כאן חולצו ממנו ישירות; במקרה של ספק — הקובץ מנצח.

## טוקנים

```css
--canvas:#EEF1F6   /* רקע הקנבס בתצוגת ההדגמה */
--bg:#F7F9FC       /* רקע המסך באפליקציה */
--ink:#0F1620      /* טקסט ראשי */

--copper:#9A5A1E   /* מבטא שני, "סיכום בלבד", חריגות */
```

צבעים נוספים שמופיעים בקובץ ואינם טוקנים — יש להפוך אותם לטוקנים:
`#c99b6c` פס ההתראה · `#ead4b9` מסגרת כרטיס מצטבר · `#e4f0e9` רקע כרטיס ניצחון · `#bc8b59` טבעת פוקוס · `#f0f2f5` רקע חשבון פרטי · `#fff8f0` רקע כפתורי ההצעות בתזרים

## טיפוגרפיה

- גוף: **Rubik**. בפרוטוטייפ מוטמעת כ-base64; **באפליקציה נטען מ-Google Fonts** — לא להטמיע.
- הלוגו `Duet` — Georgia serif, 38px, `letter-spacing:-2px`, `dir="ltr"`.
- גדלים: `h2` 27px/1.5 · `h3` 17–18px · גוף 14px/1.65 · `small`/`.meta` 12px · תוויות 11px
- הסכום הראשי: **57px, weight 300, letter-spacing -2px**, צבע `--blue`; סימן ה-₪ בתוכו 29px.
- כל מספר: `.num { font-variant-numeric: tabular-nums; white-space: nowrap }`

## סימן המותג

שני עיגולים חופפים, `dir="ltr"`: 26×26, `border 1.5px`, הראשון `--blue`, השני `--copper` עם `margin-left:-12px`.

## מחוון הנראות — הרכיב המרכזי

```
● משותף        color: var(--blue)
◐ סיכום בלבד   color: var(--copper)
○ פרטי         color: var(--muted)
```
11px, `inline-flex`, `gap:4px`, `white-space:nowrap`. **מופיע ליד כל תצוגת כסף.**

## ניווט

סדר הלשוניות התחתונות: **היום · תזרים · פעילות · הבית · טקס**
גובה 70px, רקע לבן, `border-top:1px solid --line`, פריט 64px רוחב, אייקון 20px, תווית 11px. נבחר: `--blue`; אחרים: `--weak`.
אייקוני ה-SVG (24×24, `stroke-width:1.5`, `fill:none`) קיימים בפרוטוטייפ באובייקט `icons` — יש להעתיק אותם כמו שהם.

## הגרף

SVG ידני `viewBox="0 0 320 265"`. **ציר הזמן מתקדם מימין לשמאל** — זו בחירה מכוונת ל-RTL ויש לשמר אותה.
רצועת אי-ודאות: `linearGradient` מ-`#b9cbe0` opacity .65 ל-`#e2eaf4` opacity .4. קו התחזית: `--blue`, `stroke-width:2.5`.
קו רצפה: `--copper` מקווקו `5 5`. נקודת הצוק: עיגול r=5 `--copper` עם מסגרת לבנה, קו יורד, ותווית ברקע `--warm`.
טקסט בגרף: `10px Rubik`, `fill: --muted`; הערות: `fill: --copper`.
